# 🚀 Featured Projects

## 🧠 TRIDENT

### Trust-Gated Hierarchical Memory for Multi-Agent Debate

A multi-agent AI system designed to improve reasoning reliability through role-specialized debate and trust-gated hierarchical memory.

- Four specialized agents: Proposer, Challenger, Devil's Advocate and Judge
- Multi-round agent debate architecture
- Trust-based hierarchical memory
- Short-term, episodic, semantic and procedural memory
- Evidence-based knowledge retention
- Contradiction detection and handling
- Evaluated across reasoning and fact-verification datasets

**Tech:** Python • LangGraph • ChromaDB • Mistral • Sentence Transformers

---

## 🏃 PulseBuddy

### Smart Fitness, Habit & Activity Tracking Platform

A full-stack fitness and habit-tracking application designed to help users manage daily activities, tasks, habits and fitness progress.

- Real-time fitness and activity data integration
- Step and activity tracking
- Task creation and tracking
- Habit monitoring and consistency analysis
- Activity-based insights and progress analytics
- User authentication using Supabase Auth
- PostgreSQL-backed application data
- Supabase REST APIs
- Capacitor integration for Android
- Android Health Connect integration currently in progress
- Actively under development

**Tech:** React.js • TypeScript • Vite • Tailwind CSS • shadcn/ui • Supabase • PostgreSQL • Capacitor
